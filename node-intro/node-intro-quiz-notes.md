# node-intro-quiz-notes

## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- What are the 3 components of a fullstack Web architecture?
  -frontend interacted with by users (web or app)
  -backend that takes requests from frontend and processes them
  -database where the data is stored and used across the frontend

- What is Node.js and why is it useful?
  A program that allows you to run javascript outside of a web browser, often used to build backend servers for web apps.

- What are environment variables and how do you access them in Node.js?
  Environment variables hold the configuration of the different code needed for different kinds of environments like dev, testing and production environments.

You access environment variables using 'process.env' For example, 'process.env.DB_HOST' might contain the hostname of the database server.

- What is a REPL?
  -read, evaluate, print, loop
